دليل نشر الموقع الرسمي للكاتب أ. نبيل بركات على أي استضافة (cPanel / Hostinger / etc.)
========================================================================

هذا المجلد يحتوي على النسخة الكاملة والمجهزة للنشر المباشر (Production Build).
تضم كافة الروايات والكتب الأربعة (مع القارئ التفاعلي، فهرس الفصول، النصوص كاملة)،
ومشغل الموسيقى الأدبية، ومعرض الصور والفيديوهات، وصانع السير الذاتية (CV Maker)،
وبطاقات الاقتباس، ولوحة تحكم المشرف، وكافة ملفات التنسيق والخطوط العربية.

خطوات الرفع على الاستضافة (cPanel / Apache / LiteSpeed / Nginx / Hostinger):
------------------------------------------------------------------------
1. ادخل إلى لوحة تحكم الاستضافة (cPanel) ثم افتح "مدير الملفات" (File Manager).
2. افتح مجلد الموقع الرئيسي: public_html (أو مجلد النطاق المطلوب).
3. احذف أي ملفات تجريبية سابقة أو قديمة (مثل index.html القديم).
4. قم برفع محتويات هذا المجلد مباشرة داخل public_html:
   - index.html
   - assets/ (مجلد الأكواد والتنسيقات المجمعة)
   - images/ (مجلد صور الكتب والفعاليات)
   - author.jpg (صورة الكاتب الرسمية)
   - .htaccess (ملف ضبط التوجيه والسرعة والضغط للسيرفر)
5. افتح رابط موقعك في المتصفح وسيظهر الموقع بالكامل مع كل المؤلفات والتصميم المعتمد فوراً!

ملاحظة هامة:
- الاستضافة العادية (Shared Hosting) تعمل مباشرة دون الحاجة لـ Node.js أو خادم برمجي، لأن هذا الإصدار مجهز بتقنية Static Web Application فائقة السرعة مع قواعد بيانات محلية دائمة (IndexedDB + LocalStorage).

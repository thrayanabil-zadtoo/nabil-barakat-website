موقع الكاتب أ. نبيل بركات
==========================

هذه نسخة واجهة موقع جاهزة للتشغيل محليًا، RTL ومتجاوبة مع الهاتف والكمبيوتر.

المحتوى:
- الصفحة الرئيسية مع صورة الكاتب والعبارة: «حروفي مرآتي وصمتي قصيدة».
- المؤلفات.
- الفيديوهات وروابط TikTok.
- معرض الصور.
- الأخبار.
- الروابط والمواقع.
- التعليقات.
- نموذج المراسلة.
- لوحة تحكم محلية لإضافة الكتب والأخبار والفيديوهات.

طريقة التشغيل:
1) فك الضغط.
2) افتح index.html في المتصفح.

مهم:
هذه نسخة Front-End جاهزة للعرض والتطوير، وتستخدم localStorage داخل المتصفح. لكي يصبح الموقع «خاصًا» بشكل حقيقي مع تسجيل دخول وحماية وتعليقات ومراسلات تصل إليك من أي جهاز، يجب ربطه بقاعدة بيانات وخادم (PHP/MySQL أو Node.js أو خدمة Backend مناسبة). لا تعتبر لوحة التحكم الحالية نظام حماية حقيقيًا.

لإضافة كتاب كامل لاحقًا:
يمكن تطوير قسم الكتاب ليقبل غلافًا + عدة صور + PDF + فهرس + صفحات داخل عارض كتب.
